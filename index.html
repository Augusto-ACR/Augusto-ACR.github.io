Rimainder

Rimainder es una aplicación de recordatorios con calendario que integra Telegram para avisarte de tus eventos de forma automática (1 día, 1 hora y 30 minutos antes). Cuenta con autenticación segura y permite crear eventos tanto desde la web como mediante comandos del bot.

Tecnologías: Node.js, Express, PostgreSQL, TypeORM, JWT, y Telegram Bot API.

Invitaciones para Cumpleaños

Aplicación web para crear invitaciones digitales personalizadas y compartirlas mediante un enlace único. Los invitados pueden confirmar asistencia (sí/no/tal vez) y enviar mensaje automático por WhatsApp al organizador. Incluye resumen estadístico de respuestas.

Tecnologías: Node.js + Express, PostgreSQL + TypeORM, HTML/CSS/JavaScript (vanilla), API REST y configuración por `.env` para despliegue (ej. Render).

SGGM – Sistema de Gestión de Guardias Médicas

Backend en Node.js/Express para administrar integralmente las guardias médicas de una institución: usuarios, profesionales, servicios, registro de guardias y auditoría/logging con RabbitMQ. Implementa autenticación JWT, autorización por roles, validación con Joi y una arquitectura modular por dominios (vertical slice).

Tecnologías: Node.js, Express, TypeORM, MySQL, RabbitMQ, JWT/Passport, Joi. Documentación de API disponible en Postman.

Dashboard Biblioteca Rodríguez

Panel de control para visualizar métricas y gestionar información de una biblioteca. Incluye vistas de préstamos, usuarios, catálogos y estadísticas clave con filtros, búsqueda y componentes interactivos.

Tecnologías: JavaScript (vanilla), HTML, CSS y consumo de APIs/servicios. Estructura modular y estilos responsivos pensados para uso en escritorio y móvil.
